# 🚀 Real World Chat Application (FastChat)

A **full‑featured real‑time chat application** built with the **MERN stack** (MongoDB, Express, React, Node.js) using **WebSockets (Socket.IO)** for real‑time messaging.

---

## 📌 About

FastChat is a scalable and responsive chat application that enables users to:

- 🔹 **Register & Login securely**
- 🔹 **Send and receive messages in real‑time**
- 🔹 **View active users**
- 🔹 **Chat instantly with peers**

This project was built to demonstrate a real‑world implementation of real‑time communication using modern web technologies.

---

## 🧠 Tech Stack

This application uses:

- **Frontend:** React.js  
- **Backend:** Node.js & Express.js  
- **Database:** MongoDB  
- **Real‑Time Messaging:** Socket.IO (WebSockets)  
- **Deployment Ready:** Configured to run locally or on cloud

---

## 🚀 Features

✔ **User Authentication**  
✔ **Real‑Time Messaging with WebSockets (Socket.IO)**  
✔ **Responsive UI**  
✔ **Persistent Chat History**
